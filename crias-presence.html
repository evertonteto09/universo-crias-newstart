INSTALAÇÃO

Configure em poucos passos

Leia as etapas antes de iniciar a instalação e mantenha o Discord para computador aberto ao conectar.

  1. 1

    Baixe o instalador

    Use o botão de download acima. O arquivo é o instalador do Crias Presence para Windows de 64 bits.

  2. 2

    Instale o aplicativo

    Execute o arquivo baixado e escolha instalar somente para sua conta ou para todos os usuários, conforme sua necessidade. A opção de atalho na área de trabalho pode ser marcada ou desmarcada.

  3. 3

    Abra o Discord e o Crias Presence

    O Discord para computador deve estar aberto. Inicie o Crias Presence e deixe o aplicativo em execução enquanto utiliza o site.

  4. 4

    Vincule o site com o código temporário

    No site, clique em Presença → Conectar ao programa. Permita o acesso à rede local caso o navegador solicite. Digite o código de oito caracteres exibido pelo aplicativo. Ele expira em cinco minutos e só pode ser usado uma vez.

  5. 5

    Escolha suas preferências

    No mesmo menu Presença, ajuste a privacidade, atualize a atividade ou limpe a presença. As preferências são salvas neste navegador.

🛡️

Antes de instalar

Esta é uma versão beta. Baixe o instalador somente pelo link oficial desta página. Como o aplicativo pode não ter assinatura digital reconhecida, o Windows pode mostrar um aviso de editor desconhecido. Não desative o Microsoft Defender nem ignore uma detecção de malware; em caso de bloqueio ou dúvida, interrompa a instalação e avise o responsável pelo projeto.

O código temporário serve apenas para vincular o navegador ao aplicativo local. Não o compartilhe nem o digite em páginas diferentes do Universo dos Crias.
